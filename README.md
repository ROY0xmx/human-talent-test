# 人类十大天赋自测

轻松友好的中文自我探索网页，使用原生 HTML、CSS 与 JavaScript，无需安装依赖、构建工具或后端服务。

## 使用

直接在浏览器打开 `index.html`，或将仓库部署到 GitHub Pages 等静态网页托管服务。

## 功能

- 40、100、200 题三种测评长度，覆盖语言、逻辑、空间、音乐、身体、人际、内省、自然、创造、美学十项天赋。
- 题目单选、上/下一题、键盘快捷键、进度提示，以及自动保存与中断后续测。
- 完成后展示优势前三项、十项得分、探索方向和可实践的反思建议。
- 测评记录、历史结果回看、结果摘要复制、浅色/深色主题。
- 适配手机和桌面，支持减少动态效果偏好；无需注册，数据保存在当前浏览器的本地存储。

## 隐私与说明

所有测评记录和草稿均存储在当前设备浏览器的 `localStorage` 中，不会发送至服务器。清除浏览器站点数据会删除记录。结果仅供个人探索与娱乐参考，不构成心理诊断、能力鉴定或职业建议。
